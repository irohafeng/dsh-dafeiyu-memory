# 记忆 · dsh-dafeiyu-memory

让大肥鱼记住事：换一个会话、隔些日子，再开口时还认得你。

## 给谁用的

跑 DSH 的大肥鱼，和一个希望它记得住的人。对话会换、会话会关，记忆不住在对话里——它住在一个库里，库可以放在任何地方，也可以带着走。

## 能做什么

- **记一条**：谁、做了什么、为什么；带上当时在场的人，和这件事的分量（1 到 5）。
- **想起来**：叫一声关键词（默认 `#大肥鱼`），这一步开头就把该记的翻出来——最近的事、一直记着的、攒下的心得。
- **按需找**：想不起某件事，按词找、按 id 看，不用整份翻。
- **淡出**：不重要的事慢慢淡下去，不是删掉。
- **认识的人**：每个人攒着自己的理解。
- **心得和技能**：从一件件事里攒出来的判断，和学会的做法。
- **换会话也不丢**：库绑在人身上；新开一个会话，按工作目录或 preset 自己能认回来，不用每次重新选。几个库都没绑的时候它不替你挑——会直说「还没绑，用 use 选一个」。
- **库不在也记得住**：库读不到时先写进「待补」，等库回来再并回去；拿不准的不动，等一句确认。宁可等着，也不把一个人的事写进另一个人的库。
- **隔久了先提醒**：很久没说话，先报一句隔了多久，先校一遍轻重。
- **空闲回顾**：没人说话超过一阵（默认 45 分钟），自己整理一次；两次之间至少隔几小时。

## 几个词，说人话

- **库**：一个文件夹，里面存着记忆。放哪都行，搬走也认得。
- **待补**：库暂时不在时先寄放的地方；库回来会自己并回去，看不准的等你一句话。
- **焦点**：最近在说谁——想起来时先排他的。
- **淡出**：让一条记忆不再占着注意力，但它还在。

## 工具

会话里用一个工具 `dafeiyu_memory`，用 action 决定做什么：

`brief` 想起来、`add` 记一条、`known` 看心得、`review` 通读、`search` 按词找、`show` 按 id 看、`touch` / `fade` 牵一下 / 淡出、`skills` / `skill` 技能、`actors` / `actor` / `note` 认识的人、`where` 库在哪、`flush` 并待补、`use` / `list` 换库 / 列库、`rename` 给库改名。

## 数据

| 东西 | 位置 |
|---|---|
| 记忆库（可搬） | 默认 `Documents\dafeiyu\memory`，在「设置 → 大肥鱼的记忆」里改 |
| 待补（跟机器） | 库读不到时先写这里：默认 `~\.dsh\dafeiyu-memory\待补.jsonl`；配了 CLI 就跟 CLI 的目录走（`memory\待补.jsonl`） |
| 插件偏好（跟机器） | `~\.dsh\dafeiyu-memory\config.json` |
| 运行时时间戳 | `~\.dsh\dafeiyu-memory\state.json` |

配置也可以用环境变量兜底：`DAFEIYU_STORE`（库目录）、`DAFEIYU_DIAG`（诊断日志位置）。

## 装和更新

Host 那半（`lib/`）改完重载插件就生效；Client 那半（`client.js`）得重启一次 DSH。怎么打包发布、诊断日志在哪，见 [DEV.md](DEV.md)。

升了版本，想知道这次变了什么、要不要跟着动，看 [CHANGELOG.md](CHANGELOG.md)。它一版一节，每节末尾有一段写给使用者的大肥鱼的话——升级后把那一段贴给它，或者让它自己来读。
